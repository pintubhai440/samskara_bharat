# Video Assets Directory for Samskara Bharat

Place your lesson video files here:
- `panchatantra_truth.mp4` (Class 6, Chapter: Truth, Lesson 01)
- `satyavrata_truth.mp4` (Class 6, Chapter: Truth, Lesson 02)

When placed in this folder, you can reference them in code or in the dashboard as:
`/assets/videos/panchatantra_truth.mp4`
`/assets/videos/satyavrata_truth.mp4`

You can also use external URLs (Supabase Storage, Cloudflare Stream, YouTube, Google Drive, AWS S3) directly through the in-app "Custom Video URL" feature on the video player page.
